# 问卷样本与需求调研

## 调研目的

了解养宠经历、领养意愿、救助信息获取方式，以及领养前核验与领养后照护的需求。区域按项目负责人最新提供的信息记为京津冀。

项目问卷回收量：**超过200份**。未提供逐条答卷，因此不将回收数写成有效样本数，也不推算题目比例或分地区结果。

## 问卷样本（作品集整理稿）

以下为按项目主题整理的可复用问卷样本，并非原始问卷的逐字还原。

| 编号 | 题目 | 选项或形式 | 分析用途 |
|---|---|---|---|
| Q1 | 是否自愿参加本次匿名调查？ | 是／否 | 知情同意与样本筛选 |
| Q2 | 常住城市？ | 北京／天津／河北其他城市／其他 | 区域描述 |
| Q3 | 是否有养宠经历？ | 有／无 | 分组交叉分析 |
| Q4 | 在条件允许时，是否考虑领养？ | 是／否／不确定 | 领养意愿描述 |
| Q5 | 通常从哪里获取救助或领养信息？ | 社交平台／机构／朋友／社区／其他，多选 | 渠道分析 |
| Q6 | 决定领养时最关注什么？ | 健康／性格／来源／照护条件／其他，多选 | 产品信息字段 |
| Q7 | 暂不领养的主要原因？ | 经济／居住／时间／健康顾虑／信息可信度／其他，多选 | 约束识别 |
| Q8 | 是否参加过喂养、转发或线下救助？ | 分项选择 | 救助参与方式 |
| Q9 | 上报救助信息时最需要什么？ | 明确联系人／状态反馈／位置说明／其他，多选 | 上报与状态功能 |
| Q10 | 希望领养后获得哪些支持？ | 照护知识／咨询渠道／回访／其他，多选 | 回访与科普功能 |
| Q11 | 是否愿意接受领养后回访？ | 是／否／视情况而定 | 流程接受度 |
| Q12 | 还有哪些问题或建议？ | 开放文本 | 补充需求归类 |

不收集身份证号、精确住址、电话号码等识别信息。答卷ID应是匿名编号。

## 访谈提纲

- 救助机构：信息从何处进入？如何分派？人力与资源有哪些限制？如何核验领养条件？回访怎样记录？
- 领养人：如何寻找可信信息？健康与性格资料是否充分？哪些条件影响决定？领养后如何求助？
- 社区居民：什么情况会触发求助或投诉？需要怎样的反馈？如何兼顾居民生活与动物照护？

访谈应记录“问题—具体例子—现行做法—可改进点”，而不是预设受访者会同意某个功能。

## 分工与过程

负责人统筹调查目标、问卷结构、团队任务与最终报告。成员按调研、访谈、资料整理和界面展示协作。此处不为具体成员补写未经提供的个人任务记录。

原结项报告落款为2024年5月13日。项目整体周期按最新简历信息记为2023年9月至2024年6月，二者分别指材料日期和经历周期。
